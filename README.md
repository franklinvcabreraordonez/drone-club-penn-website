# Drone Club @ Penn Website

Website for Drone Club @ Penn, a University of Pennsylvania student organization.

**Live site:** https://droneclubpenn.com

## What it is
A three-page static site (home, leadership, contact) for recruiting members and
attracting sponsors.

## Built with
- HTML and CSS (no frameworks), a small amount of JavaScript
- Responsive layout using CSS Grid and Flexbox
- Hosted on Cloudflare with a custom domain
- Cloudflare Web Analytics, sitemap and structured data for search

## My role
Software lead. I designed the layout, wrote the content structure, set up hosting
and the domain, and handled SEO and analytics. Built with AI assistance (Claude).

## Notes
Member names, photos and club branding are not licensed for reuse.

## Run locally
Open the folder in VS Code and use the Live Server extension, or open `index.html`
in a browser.
